========================================================================
IMAGE ASSETS DIRECTORY
========================================================================

Place your personal photos, project screenshots, and graphic designs here!

Recommended file naming conventions:
- profile-hero.jpg       → Your main hero portrait photo (approx 800x1000px)
- profile-about.jpg      → Your about page portrait/action shot (approx 800x1000px)
- project-01.jpg         → Featured Project 1 screenshot/mockup (approx 1200x800px)
- project-02.jpg         → Featured Project 2 screenshot/mockup
- project-03.jpg         → Featured Project 3 screenshot/mockup
- project-04.jpg         → Portfolio Project 4 screenshot/mockup
- project-05.jpg         → Portfolio Project 5 screenshot/mockup
- project-06.jpg         → Portfolio Project 6 screenshot/mockup
- project-07.jpg         → Portfolio Project 7 screenshot/mockup
- project-08.jpg         → Portfolio Project 8 screenshot/mockup
- project-09.jpg         → Portfolio Project 9 screenshot/mockup
- client-avatar-1.jpg    → Testimonial / Client avatar
- logo.svg or logo.png   → Your custom personal logo if preferred over text logo

Note: The HTML files currently use curated high-resolution editorial stock
images with placeholder comments like:
<!-- [REPLACE WITH YOUR IMAGE: assets/images/profile-hero.jpg] -->

Whenever you have your own photos, simply replace the `src` attribute with
your local path (e.g., `src="assets/images/profile-hero.jpg"`).
